## 核心脚本

- `deliverables/vol_bible.md`：30分钟叙事圣经、素材口径、场次与镜头剧情。
- `deliverables/vol5_voice.md`：台词、语音与制作语境。
- `deliverables/voice_cue.md`：逐镜声音、口型、对白、VO/OS及混音Cue。
- `deliverables/vol6_manus15.md`：180镜与120个15秒制作单元的总控提示。
- `deliverables/blocks/Manus15s_001.md`–`Manus15s_120.md`：可以逐块交给视频制作团队的独立提示。
- `deliverables/source_masters/`：40张本地源参考母带。
- `deliverables/selected_images/`：当前选取的最高可用图像修订候选；不覆盖源母带。
- `V27_5秒视频生成台账.csv`：将120个15秒单元映射为当前Manus会话可执行的360条5秒生成任务。
- `V27_统一视觉与语言规范.md`：所有镜头共用的原创动画视觉美术和中文画面指令标准。

## 当前结构核验

从本目录运行：

```bash
python3 audit_v27_candidate.py
```

本包已完成**剧本与制作流程文件**。视频、配音和混音尚未生成；制作启动、后期和发布按流程文件逐步执行。平台发布目标是哔哩哔哩与抖音。AI生成合成内容发布时须在平台发布界面主动申报并使用标识功能。
